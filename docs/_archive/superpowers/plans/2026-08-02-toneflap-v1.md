> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Take the existing Step-0 prototype (voice-driven dot + trail) to a usable v1: calibration, tone-shaped gates, collision + scoring with "couldn't hear that" neutrality, tutorial, game-over per-tone breakdown, and edge-case handling — per PRD §12 steps 1–8.

**Architecture:** All game logic (gates, run state machine, scoring, difficulty) is pure TypeScript in `src/game/` driven by the existing rAF loop in `src/game/loop.ts`; rendering is pure canvas functions in `src/render/`; React (`src/ui/`) only renders screens/HUD around the canvas and never runs per-frame state. Calibration math is pure (`src/pitch/`), capture orchestration lives in `src/audio/`, persistence in `localStorage`.

**Tech Stack:** React 19 + TS + Vite, Canvas 2D, Web Audio (AudioWorklet only), pitchy, vitest.

## Global Constraints

- Game loop is rAF outside React; never `useState` per frame; game state in module singletons / refs.
- `AudioWorkletNode` only — never `ScriptProcessorNode`.
- All pitch math in semitones, never raw Hz. `semitones = 12 * log2(f0 / f0Center)`.
- Every audio API call behind an explicit user gesture.
- `src/pitch/` has zero Web Audio imports.
- Unclear signal → "couldn't hear that": >40% unvoiced frames in a gate = neutral (no points, no heart lost). Never score the player wrong on bad signal.
- Chao→Y mapping: `y(chao) = 0.80H - ((chao - 1) / 4) * 0.60H`.
- Tolerance starts 0.12H, floor 0.07H. Gate duration 600ms. Rest interval 900ms→600ms floor. Base scroll 220 px/s, ×1.08 per 5 gates cleared, cap 2.2×. Tolerance ×0.95 per ramp, rest ×0.95 per ramp.
- Tone 3: grace 250ms (hold, no drift) inside T3 gates; tolerance ×1.3; signal loss never fails a T3 gate.
- No new runtime dependencies without asking. No backend, no persistence except calibration/settings in localStorage.
- Any change to `src/pitch/` requires fixture tests pass (`npm run test`) and golden review.
- After each task: `npm run typecheck` and `npm run test` must pass before commit.
- Existing code style: TS strict, small pure modules, comments only for non-obvious constraints.

```ts
// src/pitch/calibration.ts  (pure — no Web Audio)
export function median(xs: number[]): number {
  if (xs.length === 0) throw new Error("median of empty array");
  const s = [...xs].sort((a, b) => a - b);
  const mid = s.length >> 1;
  return s.length % 2 ? s[mid] : (s[mid - 1] + s[mid]) / 2;
}
export const NOISE_FLOOR_MIN = 1e-4;
export function computeNoiseFloor(rmsFrames: number[]): number {
  if (rmsFrames.length === 0) return NOISE_FLOOR_MIN;
  return Math.max(NOISE_FLOOR_MIN, median(rmsFrames));
}
export function computeF0Center(voicedF0s: number[]): number | null {
  if (voicedF0s.length < 10) return null;
  return median(voicedF0s);
}
```

```ts
// src/game/settings.ts
export interface CalibrationSettings {
  f0Center: number;
  noiseFloor: number;
  rangeSemitones: number; // PRD: 3–8, default 5
}
const KEY = "toneflap.settings.v1";
export function loadSettings(): CalibrationSettings | null {
  try {
    const raw = localStorage.getItem(KEY);
    if (!raw) return null;
    const s = JSON.parse(raw) as CalibrationSettings;
    if (
      typeof s.f0Center !== "number" || s.f0Center < 70 || s.f0Center > 400 ||
      typeof s.noiseFloor !== "number" || s.noiseFloor <= 0 ||
      typeof s.rangeSemitones !== "number" || s.rangeSemitones < 3 || s.rangeSemitones > 8
    ) return null;
    return s;
  } catch { return null; }
}
export function saveSettings(s: CalibrationSettings): void {
  localStorage.setItem(KEY, JSON.stringify(s));
}
export function clearSettings(): void { localStorage.removeItem(KEY); }
```

### Task 3: Scoring (pure)

**Files:**
- Create: `src/game/scoring.ts`
- Test: `src/game/scoring.test.ts`

**Interfaces:**
- Consumes: `Tone` from gates.ts
- Produces:
  - `interface GateSample { errChao: number /* |bird-centre| in chao */; tolChao: number; voiced: boolean; }`
  - `type GateOutcome = "perfect" | "good" | "ok" | "collision" | "unheard"`
  - `scoreGate(samples: GateSample[], collided: boolean): { outcome: GateOutcome; accuracy: number }`
    - if `collided` → collision, accuracy 0
    - if voiced fraction < 0.6 → unheard (PRD: >40% unvoiced ⇒ neutral), accuracy 0
    - else `accuracy = clamp(1 - mean(err/tol over voiced samples), 0, 1)`; ≥0.85 perfect, ≥0.60 good, else ok
  - `pointsFor(outcome: GateOutcome, combo: number): number` — 300/150/50/0/0 × multiplier
  - `comboAfter(outcome: GateOutcome, combo: number): number` — perfect/good increment combo count; ok/collision reset to 0; unheard leaves combo unchanged
  - `multiplierFor(combo: number): number` — 0→×1, 1→×1.5, 2→×2, ≥3→×3
  - `interface RunStats { score: number; hearts: number; bestMultiplier: number; perTone: Record<Tone, { gates: number; accSum: number; unheard: number }>; }`
  - `newRunStats(hearts?: number): RunStats` (default 3 hearts)
  - `applyGate(stats: RunStats, tone: Tone, outcome: GateOutcome, accuracy: number): RunStats & { combo: number }` — mutate-free fold; collision decrements hearts; unheard doesn't count toward per-tone accuracy average but is tallied
  - `toneBreakdown(stats: RunStats): { tone: Tone; pct: number | null; unheard: number }[]` and `takeaway(breakdown): string` — worst tone with ≥2 scored gates, e.g. `"Tone 3 is your weak spot — it dips before it rises."` (per-tone lines: T1 "keep it level", T2 "it rises, don't start too high", T3 "it dips before it rises", T4 "it falls fast — commit to the drop"); when no tone has ≥2 scored gates return "Play a longer run for a per-tone read."

### Task 4: Run state machine (pure core, rAF-driven)

**Files:**
- Create: `src/game/run.ts`

**Interfaces:**
- Consumes: gates.ts, scoring.ts, `PitchState`.
- Produces:
  - `type RunMode = "game" | "tutorial"`
  - `interface RunConfig { mode: RunMode; height: number; width: number; rand?: () => number; }`
  - `class Run` with:
    - `constructor(cfg: RunConfig)` — tutorial: fixed tone order `[1,1,4,4,2,2,3,3]`, tolerance ×2, no hearts/score; game: random via `nextTone`, 3 hearts.
    - `tickAudio(p: PitchState, nowMs: number): void` — feeds pitch: updates targetChao with voiced/grace/drift rules (T3-gate-active ⇒ 250ms grace, hold not drift), pushes trail, and while inside the active gate records a `GateSample` (`errChao = |birdChao - corridorChaoAt(tone, t)|`).
    - `tickFrame(dtMs: number, nowMs: number): void` — advances scroll `x += speed*dt`, eases displayChao, activates/retires gates, on gate end calls `scoreGate`+`applyGate`, spawns next gate at `xEnd + restMs` worth of px, applies `rampDifficulty`. Collision = any frame inside gate where `|birdChao - corridor| > tolChao` **while voiced or in grace** (unvoiced frames never collide — signal loss is not a wall).
    - `snapshot(): RunSnapshot` — everything the renderer + HUD need: `{ birdChao, voiced, pinned: "high"|"low"|null, trail, gates: {tone,x0,x1,tolChao}[], activeGate, upcoming: {tone, msUntil} | null, score, hearts, comboMult, over, stats, lastOutcome: {outcome, tone, atMs} | null, noisy: boolean }`
    - `over` true when hearts hit 0 (game mode) or 8 gates done (tutorial).
  - `pinned` set when raw chao clamped at 1 or 5 this frame (drives the edge flash, PRD §10).
  - `noisy`: over a rolling 3s window, >60% of frames voiced-but-erratic (voiced with `|Δsemitone| > maxSlew` rejected upstream shows as clarity flapping — approximate as voiced frames whose frame-to-frame chao delta > 1.5); non-blocking hint flag.
